# Armed Factions and Local Electoral Competition

Replication code for:

> Armed Factions and Local Electoral Competition: Evidence from Metropolitan Rio de Janeiro

This repository contains the scripts used to construct the analysis panel, reproduce the tables and figures, and run the numerical audit for the paper. The public GitHub repository is:

<https://github.com/vr-rodrigues/armed-factions-elections-replication>

## Repository structure

```text
code/                 Main analysis scripts
audit/scripts/        Numeric audit suite
docs/                 Research-design notes and referee memo
paper/                LaTeX source snapshot and figure folder
data/README.md        Where to obtain the underlying data
results/              Generated outputs, when reproduced locally
logs/                 Logs produced by replication scripts
```

The GitHub version is code-first. Large or restricted data files are not tracked in git. After collecting the data described in `data/README.md`, place the processed files in `data/` using the filenames listed in `MANIFEST.md`.

## Data collection

The analysis combines three inputs:

1. **Electoral returns and voting locations.** Download from the Tribunal Superior Eleitoral open-data repository: <https://dadosabertos.tse.jus.br/>.
   - Voting-section returns: `votacao_secao`
   - Candidate files: `consulta_cand`
   - Voting-location files: `locais_votacao`
   - Election years used in the paper: 2008, 2012, 2016, 2020, and 2024 for municipal elections; 2010, 2014, 2018, and 2022 voting-location files are used for geocoding continuity.

2. **Armed-faction territory maps.** Obtain annual maps for metropolitan Rio de Janeiro from the Fogo Cruzado Institute: <https://fogocruzado.org.br/>.
   - Years used: 2007-2024.
   - Redistribution of original polygons is subject to Fogo Cruzado's data-use terms.
   - The paper uses derived polling-station exposure indicators and stable faction-type classifications.

3. **Auxiliary geographic and classification data.**
   - Metropolitan Rio municipality crosswalks are generated by `code/03_municipality_crosswalk.py`.
   - RJ municipal geometry is derived from public Brazilian geographic sources and stored locally as `municipios_rj.geojson`.
   - Stable armed-group classification follows the procedure described in the paper and is cross-checked against Monteiro et al. (2022).

See `data/README.md` for the complete file list and collection notes.

## Quick start on Windows

From this folder:

```powershell
.\run_replication.ps1
.\run_audit.ps1
```

If `Rscript` or `python` are not on `PATH`, pass explicit paths:

```powershell
.\run_replication.ps1 -Rscript "C:\Program Files\R\R-4.5.2\bin\Rscript.exe" -Python "C:\Path\to\python.exe"
.\run_audit.ps1 -Rscript "C:\Program Files\R\R-4.5.2\bin\Rscript.exe" -Python "C:\Path\to\python.exe"
```

## Quick start on macOS/Linux/Git Bash

```bash
bash run_replication.sh
bash audit/scripts/run_all.sh
```

`run_replication.sh` uses `Rscript` and `python` from `PATH`. Override them with:

```bash
R=/path/to/Rscript PY=/path/to/python bash run_replication.sh
```

## Reproduced outputs

The main analysis scripts regenerate:

- main CS-DID tables;
- event-study figures;
- Honest-DiD outputs;
- clustering and estimator robustness checks;
- minimum-detectable-effect and equality-test tables;
- summary statistics, balance tables, and placebo diagnostics;
- turnout outcome tables.

The audit suite verifies numbers in the manuscript against the generated results.

## Data-use note

This repository documents all sources and code needed for replication. Public TSE data can be downloaded directly. Fogo Cruzado territory data must be obtained under the provider's terms. If data redistribution is not permitted, users should run the scripts after placing authorized copies of the raw or processed data in the paths documented in `data/README.md`.
